# ml-thyroid-cancer-recurrance
Machine learning project reconstructing a pipeline to predict thyroid cancer recurrence, and comparing multiple models for performance evaluation.

Structure:

    preprocessing.py
    training.py
    evaluation.py

README.md

## Dataset: Differentiated Thyroid Cancer Recurrence (UCI ML Repository, ID 915)
This dataset is aimed at predicting recurrance in well differentiated thyroid cancer from clinical and pathological features.

**Reference**:
Borzooei, S., Briganti, G., Golparian, M. et al. Machine learning for risk stratification of thyroid cancer patients: a 15-year cohort study. Eur Arch Otorhinolaryngol 281, 2095–2104 (2024). https://doi.org/10.1007/s00405-023-08299-w

**Data source**: 
Borzooei, S. & Tarokhian, A. (2023). Differentiated Thyroid Cancer Recurrence [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5632J.
